# 使用手册：先记录，之后再整理

适用仓库：`lanchenglin/memos-cloudflare`。本手册按 0.3.0 个人图文版编写；后续升级时以实际界面和当前源码为准。

部署交给 Hermes 时，使用 [Hermes 主动部署任务书](HERMES_DEPLOY.md)。自己部署请看 [DEPLOY.md](DEPLOY.md)。

## 1. 先认识这套笔记

这是通过浏览器使用的私人图文笔记，不是公开图床。手机和电脑打开同一个 HTTPS 地址，登录同一账号后，可以看到已经保存到云端的笔记。

- 文字、标签、时间、账号和图片关联保存在 D1。
- 上传的图片、PDF 原文件保存在私有 R2。
- 域名接在 Worker 上；不需要在网页填写 S3 Access Key，也不要公开 R2 桶。

已经保存的内容不依赖家里的电脑开机。**尚未点击保存的图片只在当前页面；文本草稿只在当前浏览器，不是跨设备同步，也不是云备份。**

## 2. 第一次打开

### Hermes 已经帮你完成初始化

直接使用 Hermes 交付的站点地址、管理员用户名和安全保存的密码登录。不再填写初始化密钥，也不要重复创建管理员。

部署报告应说明密码保存在哪个本机受限文件或密码管理器里，不能把密码写进这个公开仓库。首次登录后可以在账号设置中更换密码；旧登录凭据会被撤销，其他设备可能需要重新登录。

### 实例还没初始化

首次页面会要求创建账号。填写 `SETUP_KEY`、用户名和 12–128 字符的独立长密码。用户名使用字母、数字或连字符，不能全为数字。

`SETUP_KEY` 是部署时配置的一次性初始化凭据，不是日常登录密码。创建完成后，它可以从 Worker Secrets 删除。没有预置的通用管理员密码。

手机与电脑尽量固定使用同一个域名。`workers.dev` 地址和自定义域名可能指向同一份数据，但浏览器登录状态不通用，需要分别登录。

## 3. 随手记一条内容

打开首页，在编辑框直接写内容。无需先设计文件夹，也不必先起标题。

建议至少写一句“这是什么、为什么保存”：

```text
这个方法可能能解决 WSL 同步文件的问题，尚未测试。
来源：把原网页链接粘贴在这里。

#技术 #待整理
```

确认可见性为“私有”，点击“保存”。保存成功后应在列表看到新笔记。需要确认云端已保存时，再刷新页面检查；**有上传或保存错误时不要先刷新，以免丢掉尚未提交的图片。**

支持常用 Markdown，例如：

```markdown
## 一个小结
重点可以用 **粗体** 标出来。

- [ ] 下次尝试这个方法
- [x] 已经看完资料

#技术 #待验证
```

复杂排版不是本版重点。长文超过当前实例的正文上限时，需要拆成几条，或由管理员检查笔记相关设置；不要反复点击保存。

## 4. 图片怎么保存

电脑可以点击编辑器中的图片按钮、把图片拖进编辑区域，或粘贴剪贴板截图。手机可以点击图片按钮，从系统提供的照片或文件选择入口添加。

可以只保存图片，也可以一段文字配多张图片。图片加入编辑器后仍需点击“保存”，才会写入 R2 并关联到笔记。

| 项目 | 本版规则 |
| --- | --- |
| 图片格式 | JPG/JPEG、PNG、GIF、WebP、AVIF |
| 其他附件 | PDF 可作为附件保存和下载；本版不提取其正文 |
| 每个文件大小 | 默认 10 MiB；管理员可通过 `UPLOAD_LIMIT_MB` 设置为 1–20 MiB |
| 每条笔记附件数 | 最多 20 个 |
| 原文件处理 | 不强制压缩，不转码，不自动删除 EXIF 信息 |
| 暂不接受 | HEIC、SVG、HTML 等；仅修改后缀名不能转换格式 |

手机产生 HEIC 时，先转换为 JPG 再上传。多张大图可以分批、分笔记保存。当前图片预览仍读取原图，没有生成单独的小缩略图，大图较多时加载可能变慢。

**截图里的文字不会自动成为可搜索正文。** 建议给图片配一句描述，或在上传前起一个有意义的文件名，例如“WSL同步配置截图.png”。

## 5. 标签与“待整理”

在正文中写 `#技术`、`#生活`、`#资料` 等标签，并用空格或换行分隔。标签中不要放空格，标点与标签分开。代码块中的 `#` 不作为普通标签使用。

编辑器的“待整理”按钮用于添加 `#待整理`。它不会自动阅读内容、替你分类，也不会创建独立的任务系统。没有点击按钮或自己写标签的笔记，不会自动进入待整理视图。

首页有四个快捷筛选：

| 入口 | 用途 |
| --- | --- |
| 全部 | 查看当前其他筛选条件下的正常笔记 |
| 待整理 | 查看包含 `#待整理` 的正常笔记 |
| 图片 | 查看带图片附件的笔记，不等于只显示纯图片笔记 |
| 置顶 | 查看已经置顶的笔记 |

快捷筛选会与已有搜索、标签、日期条件叠加。明明记过却没显示时，先切回“全部”，再清除其他筛选。

整理一条笔记时，可以编辑正文，补上用途、来源、结果，添加主题标签，最后删掉正文中的 `#待整理` 并保存。**归档不等于“标为已整理”**；是否归档要看你还想不想让它出现在日常列表里。

## 6. 日后怎么找回来

### 记得词语

先搜正文里的关键词，例如“同步”“剪辑”“发票”。已关联到笔记的附件文件名也参与本版关键词检索，因此有意义的文件名很有帮助。文件还没关联笔记时，不要期待它出现在笔记搜索结果中。

### 只记得主题或时间

使用标签、日期条件，再配合关键词缩小范围。多种筛选会同时生效，查不到时逐一去掉条件。

### 记得保存过，但结果为空

按顺序检查：是否使用同一账号和实例；是否仍选着“图片”“待整理”等视图；是否有旧的搜索或日期条件；笔记是否已经归档。归档内容需要到归档入口查看，不会默认出现在首页正常列表。

当前搜索是关键词/条件检索，**不是自然语言语义搜索**。以下内容目前不能保证被找出：图片内部文字、PDF 内文、网页链接指向页面的全文、只存在于另一台设备未保存草稿中的文字。

## 7. 编辑、置顶、归档、删除

通过笔记操作菜单进行编辑、置顶、归档或删除，具体按钮名称可能随语言设置不同。

- 编辑：修改正文、标签或附件后保存；刷新确认修改已生效。
- 置顶：适合近期常用资料，不代替主题分类。
- 归档：从日常列表收起；可以在归档入口找到，导出也会包含归档笔记。
- 删除：当作不可撤销操作处理；本版不提供一个已验收的回收站恢复流程，重要内容先备份。

删除笔记与删除附件不是同一个动作。当前笔记删除会解除附件关联，原附件可能仍留在附件库并占用空间。需要真正清理原文件时，再到附件管理中核对后删除；不要把仍被笔记使用的图片随手删掉。R2 删除失败会进入重试队列，不等于立即释放全部存储。

## 8. 私有、登录可见、公开的区别

| 可见性 | 含义 |
| --- | --- |
| PRIVATE / 私有 | 日常私人记录应使用这一项 |
| PROTECTED / 登录可见 | 已登录用户可读，不等于只有自己可读 |
| PUBLIC / 公开 | 匿名访客可能读取该笔记和关联附件 |

私有是应用访问控制，不是端到端加密；有数据库、对象存储或服务端管理权限的人不因此失去读取能力。不要把同一实例的服务端管理权限交给不信任的人。

把笔记改为公开前，先检查截图中的姓名、联系方式、密钥以及原照片可能包含的 EXIF 信息。已经被别人下载的文件，不会因为之后改回私有而自动消失。

没有计划公开时保持 PRIVATE。私有图片地址不能当作公共图床链接贴到其他网站；匿名查看被拒绝属于预期保护，不应通过公开 R2 来“修复”。高级分享、SSO 等上游功能不属于本版完整验收范围。

## 9. 导出与备份不是一回事

### 网页导出：便于看文字、做整理

打开“设置 → 存储”，可以导出 JSON 或 Markdown，包含自己的笔记、时间、标签和附件清单，也包含归档内容。网页最多导出 10,000 条；更多内容使用脚本。

**网页导出没有打包原图。** 导出 Markdown 中的私有图片地址仍依赖原站点和登录状态。导出期间暂停编辑，避免不同条目处于不同修改时刻。

### 完整图文便携备份：原图也带走

让 Hermes 按 [BACKUP.md](BACKUP.md) 使用 `scripts/backup.py` 的 `backup` 和 `verify` 命令。完成后应得到：

```text
备份目录/
  manifest.json
  notes/          每条笔记的 Markdown
  attachments/    已下载的原图或 PDF
```

这里的 Markdown 使用本地相对路径。备份只包括当前用户的笔记及其关联文件，不包括账号、密码、系统设置、未关联上传文件，也不会自动抓取其他网站的外链图片。

`verify` 可以检查文件是否完整，但不等于完成数据库恢复。本版没有自动把这份 Markdown/manifest 导回 Memos 的恢复命令。

### 整站灾备：实例出问题后能恢复

还要另外保存 D1 数据库、R2 原对象、部署配置与独立保管的 Secret，并在隔离实例演练恢复。详见备份文档。**当前 Worker 的 Cron 只清理过期会话和删除队列，不执行定时备份。**

## 10. 一个低负担的使用方法

记录时：一句用途说明 + 图片或链接 + 一个粗标签。来不及想分类时加 `#待整理`。

整理时：打开“待整理”，补用途和来源，删掉没价值的重复内容，把需要持续使用的笔记置顶，然后移除已处理笔记的 `#待整理`。

找资料时：先用关键词，再用标签或日期；不要为了以后找得到而在记录时建立过细的目录。

## 11. 常见问题

| 现象 | 先做什么 |
| --- | --- |
| 选了图片，刷新后没了 | 图片可能尚未保存。本地待上传图片不能从云端恢复 |
| 正文在电脑上写了一半，手机看不到 | 尚未保存的草稿不跨浏览器/设备同步 |
| 保存或上传失败 | 保留当前页面，检查格式、大小、附件数量和登录状态，再重试 |
| 刷新后私有图片 401/404 | 固定使用同一域名，重新登录；仍异常时让 Hermes 检查 Cookie、R2 绑定和对象是否存在 |
| 找不到旧笔记 | 清除筛选，核对账号和站点，再查看归档 |
| 截图/PDF 内文字搜不到 | 目前没有 OCR 或 PDF 全文提取；把关键描述写入正文 |
| 初始化提示 403 | 由 Hermes 检查 SETUP_KEY，不要放开注册 |
| 接口提示 503 | 由 Hermes 检查 JWT_SECRET 是否已设置且长度足够 |
| 登录尝试过多 | 暂停重试，限流窗口为 10 分钟；不要用循环持续试密码 |
| JSON 导出有图片地址但离线打不开 | 使用图文便携备份，而不是仅导出 JSON |

## 实际浏览器检查

使用 Chromium、构建后的前端以及本地 workerd/D1/R2。静态资源通过测试用 ASSETS 服务绑定读取，运行结束后关闭浏览器、销毁临时数据库和对象存储。

1. 在页面填写 SETUP_KEY，创建管理员并自动登录。
2. 输入中文文字、添加待整理标签、上传中文文件名图片，保存后实际解码显示。
3. 完整刷新浏览器后，私有图片仍能通过 Cookie 鉴权显示。
4. 首页图片筛选能显示刚保存的图文笔记。
5. 390px 手机宽度无横向溢出。
6. Python 脚本通过接口备份笔记、下载原图；SHA-256 校验通过，下载字节与上传字节完全一致。
7. 新建匿名浏览器上下文读取私有图片，返回 401。

测试脚本：`backend/tests/browser-smoke.mjs`。截图输出到本地 `test-results/`，不包含真实用户数据，也不提交到仓库。GitHub Actions 的浏览器工作流可手动执行并留存测试截图。

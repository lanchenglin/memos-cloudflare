# 手机查看与图片预览修复

更新日期：2026-09-26。对应 `lanchenglin/memos-cloudflare` 个人图文分支。

## 是否支持手机

本项目有响应式网页、手机导航抽屉和小屏布局，不需要另外安装手机 App。但不能把“桌面浏览器缩到 390px 时首页不溢出”当成完整手机验收。手机浏览器、键盘、触控与图片弹窗仍需分别测试。

这次从用户报告出发，在本地隔离环境复现并修复了**图片预览**的具体问题；尚未取得用户实际手机截图或线上站点测试结果，不能断言它就是用户看到的全部异常。

## 本次已确认的问题

基线：`25c3e45487fa29c67a9c9dc3f2769b8e5373425b`。

1. 320×568 的触屏浏览器模拟中，多图预览的底部按钮放在同一行，“Reset zoom”按钮左侧为 300px、右侧为 336px，超出了 320px 屏幕。由于全屏容器裁切，即使网页本身不横向滚动，按钮仍可能不可见。
2. 原预览只有居中缩放，没有平移状态；放大后不能拖动查看被裁掉的图片边缘，也没有双指捏合和滑动切图的处理。
3. 原全屏预览固定采用 `100vh`。本次预览改用动态视口高度，并为预览头部、底部及两侧增加安全区域留白；这不等于已经用真实 iPhone 验证全部浏览器工具栏和刘海场景。

## 修复后如何使用

点击笔记中的图片打开预览。手机上的上一张/下一张与缩放按钮分行显示，预览的可点击按钮采用 44×44 CSS 像素区域。

- 用底部加减按钮缩放，或双指捏合缩放。
- 双点图片在适应窗口的 100% 与 200% 之间切换。
- 放大后用一根手指拖动，查看长截图或图片细节；不能拖到图片之外露出大片空白。
- 在 100% 时左右滑动切换图片，或使用上一张/下一张按钮。放大后的拖动不会同时触发切图。
- 点击右上角关闭；桌面仍保留键盘方向键、Escape、鼠标双击与滚轮操作。

这里的 100% 是适应预览窗口的基准，不是原文件的 1:1 像素显示；可缩放范围为 1–4 倍。超长截图需要更高放大倍率时，可另行下载原图查看。

这些改动只涉及前端展示和手势处理，未修改笔记可见性、登录规则、D1 结构或 R2 文件。

## 复测命令

先按 README 安装依赖。在仓库根目录：

```bash
npm run check
npm test
npm run build

# 按项目安装的 Playwright 版本准备浏览器。
cd backend
npx playwright-core install chromium
cd ..
npm run test:mobile

# 单独运行原有整站浏览器冒烟（本地 D1/R2）。
npm run test:browser
```

已有 Chromium 时可设置 `CHROMIUM_PATH` 指向有效可执行文件。没有浏览器或系统依赖时，应报告未运行/启动失败，不跳过后声称通过。

新脚本：`frontend/tests/mobile-browser.mjs`；隔离页面夹具：`frontend/tests/mobile-fixture.tsx`。它通过仅监听 `127.0.0.1` 的临时 Vite 服务加载实际预览组件，测试结束关闭服务和浏览器。夹具不是生产站点路由，也不会加入生产应用。

设置 `MOBILE_BROWSER=webkit` 可选择 WebKit；前提是执行环境已经具备对应浏览器及系统运行库。报告和截图写入被 Git 忽略的 `test-results/`。不要把真实私人站点截图、Cookie 或用户数据混入公开测试附件。

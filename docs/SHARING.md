## 可直接发布的中文介绍

### 分享一个我维护的个人图文笔记二开版

平时我喜欢保存各种想法、截图、链接和资料，希望先方便地记下来，之后需要时再找回、整理。

因此在 **Allhuo/memos-cloudflare** 的基础上，做了一个面向个人使用的增强版，原始项目是 **Memos**。它沿用上游的 Cloudflare Workers + D1 + 私有 R2 架构，不需要家里的电脑常开。

这版重点完善了图片上传入口、待整理 / 图片 / 置顶筛选、附件文件名检索、私有图片访问、安全初始化，以及包含原图的 Markdown 便携备份。仓库还提供中文使用手册和 Hermes 部署任务书；具备相应账号与工具权限的 Hermes 可以按文档执行配置、部署和验收。

目前以文字和图片记录为主，尚未接入 OCR 或 AI 语义搜索；网页导出不含原图，完整图文备份需要使用仓库脚本。Cloudflare 实际费用和可用额度取决于个人账号与用量，不承诺永久免费，也不把测试环境通过等同于每个生产部署都已验证。

这是 **lanchenglin 维护的二次开发分支，不是 Memos 官方项目**。感谢 Memos、Allhuo 及上游贡献者，相关版权、许可证和来源声明保留在仓库中。

项目地址：<https://github.com/lanchenglin/memos-cloudflare>
